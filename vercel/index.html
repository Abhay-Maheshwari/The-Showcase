Component Philosophy

Shadow as Border

Instead of traditional CSS borders, Vercel uses multi-layered shadow stacks to create depth, glow, and borders in a single declaration.

CSS Rule

box-shadow: 0 0 0 1px rgba(0,0,0,0.08);

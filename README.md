# THE SHOWCASE

**The Showcase** is a high-fidelity design system gallery and marketplace for design engineering excellence. It serves as a comprehensive inventory of 67+ industry-leading design systems, curated and presented in a premium "Warm Minimalism" interface.

![The Showcase Preview](src/assets/hero.png)

## ✦ Key Features

- **67+ Design Showcases**: A massive collection of design systems spanning AI, DevTools, Fintech, Automotive, and more.
- **Warm Minimalism Aesthetic**: Inspired by the **Cursor** design system, featuring a warm-cream palette, gothic typography, and oklab-space borders.
- **Infinite Brand Marquee**: A dynamic, interactive marquee that cycles through the entire collection.
- **Real-time Filtering & Search**: Instant category-based filtering and search functionality.
- **Dynamic Themes**: Full support for "Warm Light" (Cream) and "Warm Dark" (Charcoal) modes.
- **Responsive Engineering**: Optimized for all devices, from mobile to ultra-wide desktops.

## ✦ Tech Stack

- **Vite**: Ultra-fast frontend build tool.
- **Vanilla CSS**: Custom design system built with CSS variables and modern layout techniques (Grid/Flexbox).
- **Vanilla JS**: Lightweight, zero-dependency logic for filtering, search, and theme management.
- **Oklab Color Space**: Perceptually uniform border and accent treatments.

## ✦ Installation & Local Development

To run **The Showcase** locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Abhay-Maheshwari/The-Showcase.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
